# bot-barokah-purwokerto

Bot ini digunakan untuk melayani informasi harga dan layanan Aqiqah Barokah Purwokerto secara otomatis via WhatsApp.

## Fitur
- Informasi Daftar Harga Paket Aqiqah.
- Informasi Paket Kambing Guling.
- Respon otomatis 24/7.

## Cara Menjalankan
1. Clone repository ini.
2. Jalankan `npm install`.
3. Jalankan `node app.js`.
